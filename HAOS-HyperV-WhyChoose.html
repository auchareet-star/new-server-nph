คำถามที่มักถามบ่อย

ข้อกังวลที่ผู้บริหารและทีม IT มักสงสัย

Hyper-V เสถียรพอสำหรับ Hospital HIS หรือไม่? ▼
เสถียรมาก — Hyper-V ใช้ใน Healthcare ทั่วโลกรวมถึงโรงพยาบาลขนาดใหญ่
Microsoft Azure ซึ่งเป็น Cloud ที่ใหญ่ที่สุดรันบน Hyper-V ทั้งหมด ถ้าไม่เสถียรก็คงไม่มีใครใช้บริการ Azure สำหรับ HAOS โดยเฉพาะ — ปัญหาเดิมของระบบไม่ได้มาจาก Hypervisor แต่มาจาก I/O contention บน shared disk ซึ่งแก้ด้วยการแยก storage pool แยก workload ไม่ใช่เปลี่ยน hypervisor
ถ้า Hyper-V Host มีปัญหา VM ทุกตัวจะ down หมดเลยไหม? ▼
ใช่ — แต่นี่คือข้อจำกัดของ single server ไม่ใช่ข้อจำกัดของ Hyper-V
VMware บน single server ก็เจอปัญหาเดียวกัน — ถ้า server ตาย VMs ทุกตัวก็ down การป้องกัน: (1) เก็บ bare metal เดิมไว้เป็น DR standby อย่างน้อย 3-6 เดือน (2) Lenovo Premier 24×7 4HR SLA ที่อยู่ใน BOM จะส่ง engineer มาแก้ภายใน 4 ชั่วโมง (3) มี backup ที่ดีทั้งระดับ SQL และระดับ VM เพื่อ restore ได้เร็ว
ทีม IT จะต้อง train เพิ่มไหม? ยากกว่า VMware ไหม? ▼
ง่ายกว่าสำหรับทีมที่มี Windows background อยู่แล้ว
ทีม IT ที่ดูแล Windows Server อยู่แล้วจะเรียนรู้ Hyper-V ได้เร็ว — ทุกอย่างอยู่ใน Windows ecosystem เดิม VMware มี learning curve สูงกว่าถ้าทีมไม่เคยใช้ vSphere มาก่อน นอกจากนี้ Panacea-Repl+ELK เดิมก็อยู่บน Hyper-V อยู่แล้ว แสดงว่าทีมมีความคุ้นเคยบางส่วนแล้ว
อนาคตจะ upgrade หรือเพิ่ม server node ได้ไหม? ▼
ได้ — Hyper-V รองรับ Failover Cluster ถ้าต้องการเพิ่ม node ในอนาคต
ถ้าในอนาคตต้องการ High Availability จริงๆ สามารถเพิ่ม server node ที่ 2 และทำ Hyper-V Cluster ได้ VM ก็จะสามารถ Live Migrate ข้าม node ได้โดยไม่มี downtime Microsoft มีแผน support Hyper-V ถึงปี 2034 (Windows Server 2025) — long-term ชัดเจน
VMware ดังกว่า — เราเชื่อใจ Hyper-V ได้ไหม? ▼
Hyper-V อาจไม่ดัง แต่เป็น enterprise-grade ที่ใช้อย่างกว้างขวาง
ในตลาด Enterprise VMware เคยมี market share สูงกว่า แต่หลัง Broadcom เข้าซื้อ ทำให้ลูกค้า Enterprise จำนวนมาก ย้ายมา Hyper-V และ open-source alternatives — Gartner และ IDC รายงานว่า Hyper-V market share เพิ่มขึ้นอย่างมีนัยสำคัญในปี 2024 สำหรับโรงพยาบาล: เลือกเทคโนโลยีที่ เหมาะกับ workload, budget, และ team skill — ไม่ใช่เลือกตาม brand
License WS2025 ที่ซื้อมาครอบคลุมทุกอย่างจริงหรือ? ▼
ครอบคลุมครบสำหรับโครงการนี้
Windows Server 2025 Standard (16core) ×2 ที่อยู่ใน BOM ครอบคลุม:
  • Physical server 32 cores ✓
  • Hyper-V role (ฟรี รวมใน WS2025) ✓
  • สิทธิ์รัน Windows VM ได้ 4 ตัว (2 license × 2 VMs) ✓
  • Windows Admin Center (ฟรี ดาวน์โหลดแยก) ✓
เงื่อนไข: Host OS ต้องใช้ Server Core (ไม่ใช้ Desktop Experience) — ถ้าใช้ Desktop GUI บน Host จะนับเป็น 1 ใน 4 VM สิทธิ์ เหลือแค่ 3

สิ่งที่โรงพยาบาลได้รับจากการเลือก Hyper-V

สรุปผลลัพธ์ที่คาดหวังได้จริง

ด้านปัจจุบัน (ก่อน)หลัง Hyper-V β-v2
ความเร็วระบบ HIS ช้า — I/O contention บน shared disk เร็วขึ้นชัดเจน — storage pool แยก workload ตาม design β-v2
ค่าใช้จ่าย Hypervisor — ฿0 เพิ่มเติม — รวมใน license ที่ซื้อแล้ว
การจัดการ VM แยกกัน bare metal + Hyper-V รวมศูนย์บน Host ใหม่ — จัดการผ่าน WAC browser เดียว
Backup & Recovery ไม่ชัดเจน / ไม่มี plan formal VSS backup ระดับ VM + SQL backup แยกชั้น
RAM สำหรับ SQL 160 GB (เหลือ 96 GB idle) 240 GB → SQL buffer pool ใหญ่ขึ้น → query เร็วขึ้น
Support SLA ไม่ชัดเจน Lenovo Premier 24×7 4HR — engineer ถึงที่ภายใน 4 ชั่วโมง

ข้อควรทราบ: ข้อด้อยที่ยอมรับได้ Hyper-V มีข้อด้อยอยู่บ้าง ได้แก่ (1) UI ของ vSphere Client ใช้งานสะดวกกว่า Hyper-V Manager เล็กน้อย (แต่ Windows Admin Center ช่วยแก้ปัญหานี้ได้) · (2) Host OS reboot จาก Windows Update จะกระทบทุก VM — ต้องวางแผน maintenance window ชัดเจน · (3) ถ้าทีม IT คุ้นเคย VMware มากกว่า จะมี learning curve เล็กน้อย ข้อด้อยเหล่านี้ ไม่มีข้อใดที่เป็นปัญหาสำหรับ workload ของ HAOS และสามารถจัดการได้ด้วย process ที่ดี
