Section 1

Scope of Work

สิ่งที่ Outsource ต้องทำ และสิ่งที่ไม่ใช่ความรับผิดชอบของ Outsource

✅ In Scope — Outsource รับผิดชอบ
🔵ตรวจสอบ Compatibility ของ Hardware SR650 V4 และแนะนำ ESXi version ที่รองรับ — พร้อม Compatibility Report
🔵ยืนยัน License vSphere 7 Enterprise Plus ใช้กับ ESXi version ที่แนะนำได้ และครอบคลุม 2 CPU Socket
🔵ติดตั้ง VMware ESXi (version ที่ยืนยันแล้ว) บน SR650 V4
🔵Apply License และยืนยันว่า Licensed ถูกต้อง
🔵ติดตั้งและ Configure vCenter (ถ้าจำเป็นสำหรับ feature Enterprise)
🔵ตั้งค่า vSwitch / VLAN ร่วมกับ Hospital IT
🔵สร้าง Datastore แยก NVMe (DB) และ SATA (APP) ตาม RAID Spec ใน Design Options
🔵Restore VM ทั้ง 4 ตัวจาก ESXi เดิม — วาง Disk แต่ละ VM ให้ตรง Datastore ตาม Design
🔵Sign-off ว่าระบบ Production-ready ก่อน Hand-off
🚫 Out of Scope — Outsource ไม่รับผิดชอบ
🔴ติดตั้งหรือ Configure Application (HIS, HAOS)
🔴Migration หรือ Restore SQL Database
🔴Performance Tuning ระดับ Database
🔴การ Config Network ภายใน Hospital (VLAN Policy, Firewall Rule)
🔴Downtime Procedure และการแจ้ง Clinical Staff
🔴UAT และ User Acceptance
🔴งาน Support หลัง Go-live (ยกเว้นระบุใน SLA แยก)

Section 3

Constraint — ข้อห้ามที่ต้อง Sign-off

ข้อกำหนดที่ไม่มีข้อยกเว้น — ละเมิดข้อใดข้อหนึ่งถือว่างานไม่ผ่าน Acceptance

📋 ESXi version ต้องผ่าน Compatibility Report ก่อนติดตั้ง
ห้ามติดตั้ง ESXi โดยไม่มีรายงานยืนยัน — Outsource ต้องส่ง Compatibility Report พร้อม version ที่แนะนำก่อนเริ่มงาน
🚫 License ต้องครอบคลุม 2 CPU Socket
SR650 V4 มี 2 physical CPU socket — License ที่ครอบคลุมแค่ 1 socket ทำให้ผิด license term และ feature ทำงานไม่ครบ
🚫 NVMe Datastore ใช้ได้กับ DB VM เท่านั้น
การวาง VM อื่นบน NVMe จะทำให้ DB VM แย่ง IOPS กับ Workload อื่น ซึ่งเป็นสาเหตุหลักของปัญหา I/O contention เดิม
🚫 ห้าม Oversubscribe CPU/RAM หนัก
DB VM ต้องการ Resource ที่ Predictable — ถ้า over-commit จะทำให้ Query latency สูงและไม่ต่างจากปัญหาเดิม
🚨
Constraint เหล่านี้ต้องระบุใน Scope of Work ที่เซ็น Outsource ต้อง acknowledge ทุก Constraint ก่อนเริ่มงาน — ถ้าพบว่าละเมิด Constraint ใดหลัง Delivery ถือว่าต้องแก้ไขภายใน Warranty โดยไม่มีค่าใช้จ่ายเพิ่ม
Section 4

Deliverables & Acceptance Criteria

สิ่งที่ Outsource ต้องส่งมอบ และเกณฑ์ที่ถือว่าผ่าน

D1
Compatibility Report
เอกสารยืนยัน SR650 V4 + ESXi version ที่แนะนำ — ต้องส่งก่อนเริ่มติดตั้ง
D2
License Verification
ยืนยัน vSphere License ครอบคลุม 2 socket และใช้กับ ESXi version ที่แนะนำได้ — มีเอกสารประกอบ
D3
ESXi Host Ready
ESXi (version ที่ยืนยันแล้ว) ติดตั้งแล้ว, License apply แล้ว, เข้าถึง UI ได้ — ส่ง Screenshot ยืนยัน
D4
Datastore Ready
NVMe Datastore (DB) และ SATA Datastore (APP) สร้างแล้ว แยกกันชัดเจน
D5
VM Created
VM DB, APP และ Supporting VM สร้างแล้ว ตรง Spec — CPU/RAM Reserve ตามที่กำหนด
D6
Production Sign-off
เอกสาร Sign-off จาก Outsource ว่าระบบ Infrastructure พร้อม Hand-off ให้ทีม Vendor ติดตั้ง Application ต่อ
