VM Restore

Restore VM ทั้ง 4 ตัวจาก ESXi เดิม — ไม่ได้สร้างใหม่

📌
แนวทาง: Restore VM จาก Environment เดิม ไม่ใช่สร้าง VM ใหม่ VM ทั้ง 4 ตัวมีอยู่แล้วบน ESXi เดิม — Outsource Restore เข้า ESXi ใหม่ จากนั้นวาง Disk แต่ละ VM ให้ตรง Datastore ที่ถูกต้องตาม Design
# Task Owner Output
1 Restore VM DB
Restore เข้า NVMe Datastore — ตรวจสอบ Disk ทุกตัวอยู่ถูก Datastore
 Outsource DB VM restored
2 Restore VM APP
Restore เข้า SATA Datastore
 Outsource APP VM restored
3 Restore VM อื่น (Interface / Batch) — รวม 4 ตัว
Restore เข้า SATA Datastore — ยืนยันครบ 4 VM
 Outsource All 4 VMs restored
4 ตรวจสอบ CPU / RAM Allocation (ไม่ Oversubscribe)
หลัง Restore ตรวจว่า Resource ที่ assign ไม่ over-commit — ปรับถ้าจำเป็น
 Outsource Resource verified
